# 安装前须知 · NOTICE

> 请先读完本页，再在「库选择」里勾选任何一个库。

## 1. 环境声明（重要）

本插件在你的手机本地封装了一条 Android 构建链路，运行在 **proot 模拟环境**里，**没有完整 Linux 环境**：
没有 systemd、`/proc` 受限、没有内核模块与特权能力。它**不是**一台标准 Linux 服务器，也不是 WSL / 云主机。

能做的事：APK 解包与重打包、aapt2 资源编译、签名、Gradle 构建验证、DEX/smali 静态分析、Frida 载荷准备。
不能做的事：内核模块、Docker、需要 root 的注入、完整 NDK 交叉编译、长时间高负载 AOSP 编译。

## 2. 准入自检

插件启动时检查四项硬门槛，任一不通过即视为**完全不可调用**：

| 检查项 | 说明 |
| --- | --- |
| 工作目录可写 | `~/.dsh/android-buildtoolchain` 可创建文件 |
| 可执行位 | 文件系统支持 `chmod 0755` 并执行 |
| 归档工具 | `tar` 存在（解包基础） |
| 磁盘余量 | 全量约 1.2 GB，低于 1.5 GB 会告警 |

若硬门槛未通过，插件会**礼貌回绝安装**并引导移除，不会留下半成品。
移除方式：`设置 → 插件 → 构建工具链 → 移除`，再删除 `~/.dsh/android-buildtoolchain`。

## 3. 按需加载

- 安装框架本身**不下载任何库**，不默认部署全量。
- 你在「库选择」勾选哪个，才拉取哪个；每个库逐个 SHA256 校验，失败自动**整目录回滚**。
- 依赖会自动先装（例如 Gradle 需要 JDK 21）。

## 4. 可追溯性

每个库安装完成后写入 `libs/<id>/manifest.json`，字段见 `schemas/manifest.schema.json`：
版本、上游地址、本地镜像、SHA256、许可、安装时间、文件数、校验结果、修复记录。
根目录另有 `index.json` 汇总清单。**没有 manifest 的目录不属于本工具链。**
